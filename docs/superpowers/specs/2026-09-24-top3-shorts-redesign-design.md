# TOP3 쇼츠 개편 설계 (v1, 무료)

작성: 2026-09-24 · 근거: 메인 세션 진단 + 편집·마케팅·트렌드 리서치·총책임자 에이전트 합의

## 목표와 기대치

- 목표: 첫 1~3초 이탈(스와이프)을 줄이고 끝까지 보게 만들어, 프로필 링크 → 쿠팡 클릭으로 잇는다.
- 중기 목표: 확장 YPP(구독 500 + 90일 쇼츠 300만 회) → YouTube 쇼핑 태그(쿠팡 제휴, 쇼츠 안에서 클릭 가능).
- **솔직한 기대치**: 조회수 상위 쿠팡 TOP3 쇼츠는 전부 실사용 촬영 영상이었고, 사진 슬라이드형 히트는 찾지 못했다
  (자동 쇼츠 50편 → 수수료 1,720원 사례). 사진 TOP3 자동 봇은 매일 채널을 굴리는 **보조 트랙**이고,
  주력은 사용자가 주 1~2편 찍어 보내는 **사용 영상 봇(usage_bot)** 이다. v1 개편은 두 봇이 공유하는 부품으로 만든다.

## 0단계 — 막힌 것 먼저

- `main.run()`에서 `refresh_access_token`을 **맨 앞**으로 옮긴다. 토큰이 무효면 Claude 호출·렌더링 전에 바로 실패.
- 사용자 작업(아래 체크리스트 1~3)으로 새 채널 테스트 업로드 1건이 **공개 상태**로 올라가는지 확인
  (미인증 API 프로젝트 업로드는 비공개로 잠길 수 있음).

## 1. 입력 — `products.txt`

```
[3만원 이하 방한템]
난방텐트 | https://link.coupang.com/a/aaa | https://...jpg https://...jpg | 포인트: 침대 위에 치는 텐트형, 체감 온도 올려줌
극세사 담요 | https://link.coupang.com/a/bbb | https://...jpg | 포인트: 리뷰 3만 개, 세탁기 가능
문풍지 | https://link.coupang.com/a/ccc | https://...jpg | 포인트: 창틀 외풍 차단, 붙이기만 하면 됨
```

- `[주제]` 줄이 묶음 시작. 아래 상품 2~5줄(권장 3)이 한 영상. **적은 순서 = 1위→3위**, 영상은 3위→1위로 공개.
- 칸: `상품명 | 쿠팡 파트너스 링크 | 이미지 주소(공백으로 여러 개, 최대 3) | 포인트`.
  - **포인트 필수.** 사용자가 아는 사실 1줄. 대본의 모든 주장·순위 근거는 여기서만 나온다.
  - 이미지 주소는 쿠팡 썸네일(`thumbnail.coupangcdn.com/thumbnails/remote/640x640ex/image/...`)을 붙여넣으면
    코드가 원본(`image1.coupangcdn.com/image/...`, 확인 결과 800~1000px)으로 바꿔 받고, 실패하면 붙여넣은 주소로 받는다.
- 블록 밖 상품 줄(옛 형식)은 경고 후 무시.
- 위에서부터 안 올린 묶음 1개를 고른다. 중복 방지 키 = 묶음 링크들을 이은 문자열의 해시(`shorts_posted_ids.json` 재사용).

**품질 게이트** — 아래면 그날 업로드하지 않고 텔레그램으로 사유를 알린다(기존 봇 토큰 재사용):
포인트 누락 / 상품 사진을 하나도 못 받음 / 대본 검증 2회 실패 / 남은 묶음 없음.
업로드 성공 후 남은 묶음이 2개 이하이면 알림.

## 2. 대본 — `script_writer.py`

- 모델: Haiku 4.5 → **Sonnet 5**(`claude-sonnet-5`). 상품별 첫 사진을 이미지 입력으로 함께 보낸다. 편당 소액 비용 발생(완전 0원 아님).
- 코드가 영상마다 `style`을 무작위로 정해 프롬프트에 넣고 기록한다: 훅 유형(결과·손실형 2/3, 퀴즈형 1/3), 배경 팔레트.
- 출력은 순위 고정 필드가 아니라 **장면(beat) 리스트** — 다음 포맷(다이소 비교형 등)은 프롬프트와 장면 순서만 바꿔 추가.

```json
{
  "title": "유튜브 제목",
  "hook_lines": ["안 쓰면", "고생하는 방한템"],
  "labels": ["난방텐트", "극세사 담요", "문풍지"],
  "beats": [
    {"kind": "hook",   "product": 0, "text": "올겨울 *이거* 없으면 진짜 고생해요"},
    {"kind": "item",   "product": 2, "rank": 3, "text": "3위는 *문풍지*예요"},
    {"kind": "item",   "product": 2, "rank": 3, "text": "붙이기만 하면 *외풍*이 막혀요"},
    {"kind": "reveal", "product": 0, "rank": 1, "text": "대망의 1위는 *난방텐트*"},
    {"kind": "outro",  "product": 0, "text": "여러분 1위는 뭐예요?"}
  ],
  "keywords": ["방한템", "자취템"]
}
```

- `product`는 입력 상품 인덱스(0 = 1위). 장면 한 개 = 한 호흡(25자 이내). `*강조어*`는 화면에서 노랑, 음성에선 제거.
- 전체 대사 길이로 **22~26초**를 맞춘다(+20% 속도 기준 약 140~170자). 3위 구간이 가장 짧고 1위가 가장 길다.
- 훅: 첫 문장에 상품명으로 시작하지 않는다. 결과·손실형 예시("안 쓰면 고생하는", "늦게 살수록 후회하는",
  "주변엔 말하지 마세요", 계절 해결형)를 프롬프트에 넣는다. 퀴즈형이면 "1위 맞혀보세요".
- **생성 후 검사**(위반 시 사유를 붙여 1회 재요청, 또 실패하면 스킵+알림):
  - 1인칭 사용 후기: `써봤|써보니|써 보니|제가|저는|내돈내산|직접 써` 등 → 사진 봇에선 금지(usage_bot은 실제 사용이므로 허용).
  - 근거 필요 주장: `품절|매출|판매 1위|직원|극찬|재구매율|전기료|절감|화재|안전 인증` 및 숫자+% → 해당 상품 포인트에 같은 말이 없으면 위반.
  - 가격 금액 언급 금지, 장면·상품 인덱스 범위, 총 글자 수 범위.

## 3. 음성 — `tts.py`

- 대본 전체를 **한 번에** 합성(edge-tts, `ko-KR-HyunsuMultilingualNeural`, `rate="+20%"`, `boundary="WordBoundary"`).
  → 한 개의 mp3 + 어절별 (시작, 끝, 글자). 로컬에서 한국어 어절 타이밍이 나오는 것 확인함(16/16 어절).
- 어절을 장면 텍스트와 순서대로 맞춰 **장면별 시작·끝 시각**을 얻는다(문장 사이 공백의 중간을 경계로).
- 실패 시 대체: Azure로 전체 1회 합성 + 글자 수 비례 타이밍(ffprobe 길이 기준).
- ponytail: 어절 매칭이 어긋나면(TTS가 숫자를 풀어 읽는 등) 글자 수 비례로 떨어진다 — 샘플에서 확인.

## 4. 화면 — `video_assembler.py` (두 봇 공용, 기존 drawtext 조립 코드 대체)

1080×1920, 30fps. 화면 레이어와 글자 레이어를 분리한다.

**화면(장면별 무음 클립 → 이어 붙이기)**
- 배경: 순위별 밝은 단색(팔레트 중 style로 선택). 검정·남색 레터박스 폐기.
- 가운데 1:1 상품 사진(폭 1080). 장면을 **2초 이하 컷**으로 나눠 컷마다 줌 프리셋(천천히 확대 / 1.12배 펀치 / 살짝 이동)
  또는 사진(여러 장이면)을 바꾼다. zoompan 떨림 방지로 먼저 크게 키운 뒤 적용.
- 훅: 결과·손실형은 1위 사진, 퀴즈형은 1위 사진 블러 + "?".
- 1위 공개(reveal): 기존 `effects/focus_lines_*.png` 집중선 재사용.
- usage_bot: 화면 = 실사용 영상 구간(`(영상, 시작초)`), 남으면 마지막 프레임 정지(기존 동작 유지).

**글자(ASS 자막 1개, `fontsdir=fonts`로 번인)**
- 광고 표기: **첫 2초와 마지막 2초**에 "광고 · 쿠팡 파트너스 활동으로 수수료를 받을 수 있음" — 읽을 수 있는 크기(약 44px).
- 훅 문구: 훅 장면 동안 중앙 큰 글씨(기존 노랑/흰 + 흰 바깥 테두리 스타일 유지).
- 헤더: 훅 이후 끝까지 상단에 주제 + "TOP3".
- 순위 뱃지: item/reveal 장면 시작마다 "3위 · 라벨" 팝 등장.
- CTA: reveal 장면 동안 상단에 "제품은 프로필 링크 #번호".
- 자막: 어절 1~2개(8자 이내) 단위 팝 자막, `*강조어*`는 노랑. 폭 900px 이하, 하단 20%·우측 버튼 영역 회피.

**소리(최종 1패스)**: 나레이션 + BGM(작게, 반복, 끝 페이드) + 효과음(순위 전환 휙, 1위 띵; `sfx/` 파일이 없으면 생략)
→ `loudnorm` -14 LUFS.

## 5. 업로드·설명란 — `youtube_api.py`, `description_builder.py`

- 제목 `[광고] ` 유지. snippet에 `categoryId: "26"`, `defaultLanguage: "ko"`.
- status에 `selfDeclaredMadeForKids: false`, `paidProductPlacementDetails.hasPaidProductPlacement: true`(유료 광고 포함 라벨).
- `containsSyntheticMedia`: **사용자 결정 대기**(아래 미결).
- 설명란: 쿠팡 고지 → "📌 왼쪽 아래 채널명 → 프로필 링크 #번호" 안내 → 1~3위 상품명 + 링크 원문(복사용) → 해시태그.

## 6. 프로필 링크 페이지 — GitHub Pages

- 업로드 성공 시 `posted_videos.json`에 기록(번호, 날짜, 주제, 영상 URL, 상품명·링크, style).
  영상 번호 = 기록 개수 + 1 (렌더링 전에 정해 영상 속 "#번호"에 사용).
- 기록으로 `site/index.html` 한 장을 만든다: 맨 위 쿠팡 고지, 최신 영상부터 "#번호 주제 → 순위별 상품 링크".
  쿠팡으로 자동 이동 없음, 도메인(`ywf2661.github.io/authshorts`)에 '쿠팡' 없음. 저장소 공개 확인됨 → 무료.
- 워크플로에서 Pages 배포(actions/upload-pages-artifact + deploy-pages).

## 7. 운영

- cron: 평일 KST 19시 `0 10 * * 1-5`, 주말 KST 11시 `0 2 * * 0,6`. 하루 1편 상한.
- `shortsbot.yml`에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_CHAT_ID` 추가(알림용). `HF_API_KEY` 제거.

## 8. 삭제

- AI 삽화 생성(HF·Pollinations `generate_image`), `image_prompts`, 블로그 봇 잔재(`raw_image_url`, `insert_images`).
- drawtext 자막·제목 코드, 문장별 TTS 합성 루프, `emphasis` 인덱스.

## 9. 2단계 이후 (이번 범위 아님)

실사용 영상 비중 확대(주 1~2편, 가장 우선) → "다이소 vs 쿠팡" 비교형 포맷 → ③②① 진행 표시·새 플래시·효과음 로테이션
→ 재생목록 자동 추가(`youtube` 스코프 재동의 필요). 판단 근거는 `posted_videos.json`의 style과 스튜디오 수치.

## 검증

- 단위 테스트: 묶음 파싱·게이트, 대본 검증(1인칭·근거 없는 주장·길이), 어절→장면 타이밍 매칭, ASS 생성, 설명란, 페이지 생성.
- 실제 렌더링: ffmpeg 정적 빌드를 임시 폴더에 받아 실제 쿠팡 사진 + edge-tts로 샘플 영상을 만든다(업로드 없음, 대본은 고정 예시).
  소리 켜고/끄고 확인 후 사용자 승인. usage_bot 경로도 짧은 테스트 영상으로 1회 렌더링.

## 사용자 체크리스트

1. OAuth 동의 화면 **프로덕션 게시** → 같은 client ID/secret으로 새 refresh token 발급 → 로컬 검증 "성공".
2. Repository secrets 4개(`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `YOUTUBE_REFRESH_TOKEN`, 새 `YOUTUBE_CHANNEL_ID`) 교체
   → 테스트 1편이 **공개**로 올라가는지 확인.
3. 새 채널명·핸들에 '쿠팡' 금지, 채널 설명에 쿠팡 고지 + "사람이 직접 고른 상품" 기준 명시.
4. YouTube 오디오 보관함에서 "저작자 표시 불필요" 밝은 비트 BGM 2~3곡, 효과음 3개(휙·뿅·딩) 준비.
5. 첫 7묶음: 3만원 이하 방한·자취·주방템, 11월 행사(11/11, 11/19 수능, 11/27 블프) 대비. 순위마다 근거 있는 포인트 1줄.
   아이폰·맥미니 등 고가품, 의료기기·건기식, 사전예약 상품 제외. 전기매트·히터류는 수치 주장 금지.
6. 저장소 Settings → Pages → Source를 "GitHub Actions"로. 주소가 나오면 채널 프로필 링크 1순위로 등록.
7. 매주: 7묶음 추가, 실사용 영상 1~2편 촬영 → 텔레그램 봇, 스튜디오 "시청함 vs 스와이프"·조회수 기록.

## 성공 지표·피벗 기준 (추정치)

- 2주: "시청함" 50% 미만 → 훅 문구·첫 화면 교체.
- 4주(약 25편): 조회수 중앙값 300 미만 → 실사용 영상 비중부터 확대, 주제를 더 좁은 상황형·낮은 가격대로.
- 8주: 누적 10만 회 이상인데 판매 0 → 링크 동선(페이지·#번호 CTA) 점검.
- 12주: 구독 100명 미만 → 실사용 중심으로 전면 전환.
